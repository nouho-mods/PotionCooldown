# Potion Cooldown

Potion Cooldown is a lightweight NeoForge mod that adds a configurable global cooldown to all potions, including drinkable, splash, and lingering types. The cooldown duration is fully configurable, and the mod enforces the cooldown visually using the vanilla cooldown bar.

## Features
- Configurable global cooldown for all potion types (drinkable, splash, lingering)
- Cooldown duration can be set in the config file
- Cooldown is visually displayed using the vanilla cooldown bar
- Works with modded potions
- No new items or blocks

## Installation
1. Download the mod JAR from [Modrinth](https://modrinth.com/mod/potion-cooldown) or your preferred source
2. Place the JAR file in your Minecraft `mods` folder
3. Configure the cooldown duration in the generated config file if desired
4. Launch Minecraft with the NeoForged mod loader

## Compatibility
- Compatible with most mods that add new potions
- Only required server side, but best results if installed on both client and server (so that the client sees the cooldown bar)
